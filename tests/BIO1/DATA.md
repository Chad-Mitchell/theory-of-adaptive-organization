# BIO1 data

This test is a literature check. Predictions and results are in `PREDICTIONS.md` and `RESULTS.md`.

Local copies of papers and extracted text were used on the machine that ran the test. They are **not** stored in this repository (published articles are copyrighted). `sources/INDEX.md` lists every local file that was used and, in `RESULTS.md`, the public links and DOIs for the numbers that were scored.

To re-read a source, fetch it from the publisher, arXiv, Europe PMC, or the URL given in `RESULTS.md` / `sources/INDEX.md`.
