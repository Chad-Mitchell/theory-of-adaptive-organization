## 2. M11′ in Lean: is the statement what is claimed?

`m11_cube_polytope (hA : 0 < mA) (hB : 0 < mB) (V) (hV : V.Finite) (hS : convexHull V ⊆ maxSet) (hP : pureSet ⊆ convexHull V) (hfA : ∀ i, flipA_i '' S = S) (hfB : ∀ j, flipB_j '' S = S) (T : unit) (hT : T '' S = S) : T '' pureSet = pureSet`.
`m11_cross_polytope` is the same with `maxSetX`/`pureSetX`, plus `hsA`/`hsB` (local coordinate swaps).

**Definitions (faithful).**
- `maxSet`: `x₀₀ = 1` and every product of facet functionals `(1 + s a_i)(1 + t b_j)` is ≥ 0. For a polytope
  part with all effects, the effect cone is generated by the facet functionals, so this is the maximal tensor
  product in local-tomographic coordinates. `maxSetX` likewise uses the cross-polytope facets `1 + s·a`.
- `pureSet` / `pureSetX`: products of the vertices (sign vectors, and `±e_i`). These are the pure product states.
- Reversible map: `autSet S`, the invertible matrices with `T '' S = S`. This matches §17 ("every linear
  bijection T with T(S) = S"). Normalization is not assumed separately; it follows because S lies in `x₀₀ = 1`
  and spans.
- "Between min and max": Lean uses `pureSet ⊆ S`. Since S is a convex hull, this is the same as min ⊆ S.

**The strict separation is derived.** `m11_cube`: averaging gives `A = Σ ρ(γ)ᵀρ(γ)`, which is invariant with
diagonal ≥ 1. Flip invariance makes `A` diagonal (`flip_invariant_diag`). On `maxSet` every coordinate has
`|x_u| ≤ 1` (`maxSet_sq_le`, from the four facet products), so `q ≤ tr A`, with equality only when every
coordinate is ±1 (`diag_form_max`). Those points are products (`pure_of_sq_one`, proved from the facet
inequalities). The cross-polytope case adds swaps, which make the diagonal constant on blocks
(`swap_invariant_blocks`); `sq_le_of_l1`, `maxSetX_frob` (Lemma 1, `‖C‖²_F ≤ 1` by sign-vector averaging) and
`pure_of_eqX` follow. Only after that comes `final_assembly` with `E := S`, so no hypothesis of the core form is left.

**`autSet_finite` (faithful).** For `S = conv V` with V finite and spanning, each `T` permutes the finite set of
extreme points (`image_extremePoints`), and Krein–Milman gives `S ⊆ span E`. So `T` is determined by a
permutation of `E`, and `autSet` injects into `E → E`. `pureSet_span`/`pureSetX_span` supply the spanning
from `hP`.

**Is the flip/swap invariance a hidden group hypothesis?** No. It is M11′'s own premise that "S is locally
symmetric, (g⊗h)(S) = S", stated for generators of the local group (the flips `diag(rowSign i)` = g⊗1 with g a
coordinate reflection). For cubes Lean needs only the sign flips, a subgroup of Aut(cube), so the premise is
**weaker** than §17's. For cross-polytopes, flips and swaps generate the full hyperoctahedral group, so the
premise is exactly §17's. What has been removed is the hypothesis on `Γ` (a finite group containing the local
maps), because `Γ = Aut(S)` is now built. So "no group hypothesis" is true of `Γ` but not of S's symmetry (M2).

**Vacuity.** The premises can be met: `V = pureSet` (2^{m_A+m_B} points) gives `conv V ⊆ maxSet` because
maxSet is convex and contains pureSet (`pureProd_mem_maxSet`), and the flips permute pureSet; `T = 1` meets `hT`.
S = maxSet itself (a bounded polytope) also works. The same holds for cross-polytopes. No Lean `example`
exhibits an instance (L2). For m_A = m_B = 1 (the segment, a classical bit) the theorem holds trivially: all
vertices of max are products, and CNOT is allowed. This is consistent with M11′'s conclusion ("permutes
product pure states", not "is local").

**How much of §17 M11′ this covers (proved-in-model).**
- Covered: parts both hypercubes `[-1,1]^{m}` (m_A, m_B ≥ 1, possibly different), or both cross-polytopes;
  S a polytope (the convex hull of a finite set) with min ⊆ S ⊆ max, invariant under the local flips (cubes) or
  flips and swaps (cross-polytopes); the conclusion is §17's. The cube version also covers composites that are
  invariant only under flips, which is more than §17 states for cubes.
- Not covered: mixed pairs (cube with cross-polytope), which §17 allows since P_A ≠ P_B; the other §17 parts
  (octahedron × octahedron, cube ⊕ cube, other vertex-transitive Hanner polytopes); closed convex S that is
  not a polytope; non-standard coordinates (fine up to linear equivalence, but not stated in Lean).
